游戏名称：God of barbarian

完成日期：2025.7.13

团队成员：GD12-Yolanda, Zachary

游戏新增内容

1. 角色按键
  - <1> 数字1-技能1，狂怒，使用后玩家攻击变快，移动变快，进入无敌状态，持续7s，冷却20s，使用时会吸引周边敌人
  - <2> 数字2-技能2，陨石，使用后对面前方形2.5m*2.5m内的敌人造成100伤害，冷却20s，使用时会吸引周边敌人
  - <3> Shift-奔跑，长按奔跑
  - <4> E-交互，用于拾取，与存档点交互
  - <5> Space-跳跃
  - <6> RMB-翻滚

3. 场景交互
  - <1> 血瓶：玩家靠近后按E拾取后恢复100血量
  - <2> 存档火盆：玩家靠近后按E交互能够将当前位置记录为存档点

4. AI敌人
  - <1> 击杀敌人回回血30
  - <2> 一个AISpawner只会重生敌人2次
  - <3> 新增BOSS，Boss为大型哥布林，300血量，随着血量的减少体型也会变小，无特殊机制

6. 关卡
  - <1> 任务系统：关卡中存在五个任务，玩家完成五个任务后游戏胜利。任务分为到达目标点与杀死目标人物两种。玩家未完成当前任务时无法进入下一区域（会被空气墙阻隔）。
  - <2> 使用美术素材为
    - 场景素材：FAB-Pirate Stilt Village Island Modular Pack, https://www.fab.com/zh-cn/listings/c267d4e2-deb0-46cf-a36f-7ac66e7758a2
    - 血瓶素材：FAB-Health potion, https://www.fab.com/zh-cn/listings/1646728b-ca4f-493a-a934-4c529280e10a

7. UI
  - <1> 游戏开始时的UI界面WBP_GameStart
  - <2> 游戏结束时的UI界面WBP_GameWin
  - <3> 游戏中按键提示UI界面WBP_InGame
  - <4> 游戏中使用TAB呼出任务提示界面WBP_TabMenu
